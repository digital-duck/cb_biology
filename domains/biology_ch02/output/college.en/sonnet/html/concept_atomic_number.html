Atomic Number

Definition. The atomic number of a chemical element, denoted $Z$, is the number of protons contained in the nucleus of every atom of that element. Because atoms in their neutral state carry no net electric charge, $Z$ also equals the number of electrons occupying the surrounding orbitals. The atomic number is the defining property of an element: two atoms with the same $Z$ belong to the same element, while atoms with different $Z$ values are necessarily different elements. No atom of the same element can have a different proton count than another atom of that element.

Worked example. Consider an atom with $6$ protons in its nucleus. By definition its atomic number is $Z = 6$, identifying it unambiguously as carbon. In a neutral carbon atom, there are also exactly $Z = 6$ electrons, arranged as $1s^2\,2s^2\,2p^2$. Any atom found in nature with $6$ protons — regardless of any other property of its nucleus — is classified as carbon, since it is the proton count alone that fixes elemental identity.

Key theorem. (Uniqueness of elemental identity). Let $X$ and $Y$ be atoms with atomic numbers $Z_X$ and $Z_Y$. Then $X$ and $Y$ are atoms of the same chemical element if and only if $Z_X = Z_Y$. The forward direction follows from the periodic law: chemical behavior is governed by electron configuration, which is determined entirely by $Z$ for a neutral atom. The converse holds because elements are classified by proton count by definition (per IUPAC convention).
